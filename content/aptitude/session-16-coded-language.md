# Session 16 — Coding & Decoding: Coded Language

**Duration** 50 min total — **45 min instruction + 5 min buffer** (3 min settling at the start, 2 min flex at the end) · **Topic** Letter-shift/mirror substitution, sentence decoding via elimination, and symbol-based codes · **Prerequisite** Number Series, Alphabet Series, Odd Man Out & Analogy — letter-to-position conversion and pattern discipline
**Session type** Lecture + guided practice. No source slide deck — content from the session's concept-explanation text. ---

## Learning Objectives

By the end of this session, students will be able to:

1. Decode and encode words using letter-shift (+n/−n) and mirror-position (A↔Z, B↔Y) substitution. *(APPLYING)*
2. Extract a specific word's code from multiple coded sentences using elimination logic. *(ANALYZING)*
3. Interpret symbol-based codes using the same elimination approach applied to symbols instead of letters. *(ANALYZING)*
4. Verify a decoded pattern's consistency across every given term before finalising an answer. *(EVALUATING)*

## Hook (7–10 min)

Say: *"If in a certain language, 'DOG' is written as 'FQI,' what would 'CAT' be?"*

Give students 30 seconds to guess the rule, then solve together: *"D+2=F, O+2=Q, G+2=I — every letter shifts forward by 2. So CAT: C+2=E, A+2=C, T+2=V — CAT becomes ECV."*

> *"That's the whole idea of coded language — someone hides a rule, and your job is to find it from a small example, then apply it consistently. By the end of today you'll crack shifts, whole coded sentences, and even codes made of symbols instead of letters."*

## Teaching Block A (10–19 min) — TEACH FROM NOTES BELOW

Covers: letter-shift and mirror-position substitution, worked live.

**Beats to emphasise**

- **Letter-shift substitution.** Every letter moves forward or backward by a fixed number of positions (+n or −n). Convert letters to positions (A=1...Z=26) to spot the shift quickly.
- **Worked example, live (from the source, verified):** *"CAT = DBU — what's the shift?"* C+1=D, A+1=B, T+1=U → consistent **+1 shift** throughout.
- **Worked example, live (from the source, verified):** *"PAN = RCP — what's the shift?"* P+2=R, A+2=C, N+2=P → consistent **+2 shift** throughout.
- **Say explicitly:** *"Always check EVERY letter, not just the first one — a real shift pattern must hold consistently across the whole word, or you've got the wrong rule."*
- **Mirror-position substitution — a different rule entirely.** Instead of shifting, each letter maps to its mirror partner across the alphabet: **A↔Z, B↔Y, C↔X**, and so on. The pattern: mirror position = 27 − normal position (same formula as reverse alphabet numbering from Session 14).
- **Worked example, live:** *"Using mirror logic, what does 'BAD' become?"* B(2)→27−2=25→**Y**. A(1)→27−1=26→**Z**. D(4)→27−4=23→**W**. **BAD → YZW.**

**Checkpoint (at 19 min)** — 10 s silent think, cold-call two students:
> *"If the shift rule is +3, what does 'BOX' become?"*
> **Answer:** B+3=E, O+3=R, X+3=A (wraps past Z: 24+3=27→27−26=1→A) → **BOX → ERA**.

## ⚡ ALS Activity 1 — Whiteboard Race: Crack the Shift (19–25 min)

**ALS format:** Paired Whiteboard Race — pairs race to find the shift or mirror rule from a given example, then apply it to a new word, first correct board up wins the round. Chosen to drill both substitution types into fast recall before Teaching Block B introduces sentence-level decoding.

**Setup line:**
> *"Pairs, boards up. I'll give you an example pair (word → code) and a new word. Find the rule, apply it, first correct board up wins. Three rounds."*

- Round 1: *"SUN = TVO. What shift, and what does 'BIG' become?"* → shift +1 → B+1=C, I+1=J, G+1=H → **CJH**.
- Round 2: *"MAP = OCR. What shift, and what does 'RUN' become?"* → shift +2 → R+2=T, U+2=W, N+2=P → **TWP**.
- Round 3: *"Mirror logic: what does 'CAB' become?"* → C(3)→24→X, A(1)→26→Z, B(2)→25→Y → **XZY**.

**How it surfaces:** After each round, have the winning pair state the rule (shift amount, or mirror) out loud before revealing the coded word — the rule identification is the actual skill.

**Debrief line:**
> *"Every one of these took the same two steps: figure out the rule from the example, then apply it letter by letter to the new word, checking every letter."*

**Cut rule:** If running short, cut to 2 rounds (drop Round 3), but always require the rule to be named before the coded answer.

## Teaching Block B (25–32 min) — TEACH FROM NOTES BELOW

Covers: sentence decoding via elimination, and symbol-based codes.

**Beats to emphasise**

- **Sentence decoding — the elimination method.** When multiple sentences are coded, find a word that repeats across two sentences — the code that also repeats between those two sentences must be that shared word.
- **Worked example, live (from the source, verified):** *"'Sky is blue' → 'mi la zo'. 'Blue is bright' → 'zo la ki'."*
  1. Shared word between the two sentences: **"blue"** and **"is"**.
  2. Shared codes between the two coded lines: **"zo"** and **"la"**.
  3. Match by checking word order: since "blue" appears last in sentence 1 and first in sentence 2, and "zo" appears last in code 1 and first in code 2 → **blue = zo**. Since "is" appears in the middle of both → **is = la**.
  4. By elimination: sky = **mi**, bright = **ki**.
- **Say explicitly:** *"Write the sentences and their codes stacked vertically, word under word where you can. Overlaps jump out visually once you do that — don't try to do this in your head."*
- **Symbol-based codes — same method, different symbols.** Letters/words map to symbols instead of other letters; the elimination method is identical.
- **Worked example, live (from the source, verified):** *"'Work hard always' = % $ @. 'Hard life balance' = $ # &."* Shared word: **"hard"**. Shared symbol: **"$"** → **hard = $**.

**Checkpoint (at 32 min)** — cold-call:
> *"In the sentence example above, what's the code for 'sky'?"*
> **Answer:** **mi** — the remaining code in sentence 1 once "blue"(zo) and "is"(la) are removed.

## ⚡ ALS Activity 2 — Silent Solve → Vote-Lock → Reveal: Three-Sentence Elimination (32–40 min)

**ALS format:** Silent Solve, Vote-Lock, Then Reveal — students work a three-sentence elimination puzzle on their own before the answer is revealed. Deliberately different register from Activity 1's loud paired race (quiet, individual, single big reveal), and uses three sentences (harder than Teaching Block B's two) to force genuine elimination logic, not just pattern-matching by eye.

**Setup line:**
> *"On your own, three minutes. Here are three coded sentences:*
> *'cats love milk' = 'pa ta ra'*
> *'dogs love bones' = 'sa ta la'*
> *'cats chase dogs' = 'pa ka sa'*
> *Find the code for 'chase.' Write your answer and your reasoning, hold it up when I say show."*

Give 3 minutes silent work, then: *"Show me — three, two, one, show."*

**The reveal, step by step:**
1. Sentences 1 & 2 share **"love"** → shared code **"ta"** → **love = ta**.
2. Sentences 1 & 3 share **"cats"** → shared code **"pa"** → **cats = pa**.
3. Sentences 2 & 3 share **"dogs"** → shared code **"sa"** → **dogs = sa**.
4. In sentence 3 ("cats chase dogs" = "pa ka sa"), cats=pa and dogs=sa are already known → the remaining word is **chase**, remaining code is **ka**.
5. **chase = ka.**

**Debrief line:**
> *"Three sentences, three overlaps, three eliminations — and the answer for 'chase' never appeared directly next to the word 'chase' anywhere. You found it entirely by removing everything else first. That's the real skill this whole session is built on."*

**Cut rule:** If running short, cut the silent window to 2 minutes but always walk through all three pairwise overlaps in the reveal — skipping one breaks the logical chain.

## Common Misconceptions

| Misconception | Why students hold it | Correct it live by |
|---|---|---|
| Checking just the first letter's shift is enough to confirm the rule | Assumes one match proves the whole pattern | Teaching Block A's explicit "check every letter" requirement |
| Shift and mirror substitution are the same kind of rule | Both involve letter-to-letter mapping | Explicit separate worked examples and separate formulas for each |
| Sentence decoding can be done "in your head" without writing anything down | Feels like a small enough problem to skip the visual step | Teaching Block B's explicit "write it vertically" instruction |
| A shared word's position in the sentence doesn't matter for matching its code | Assumes any overlapping code must match any overlapping word | Teaching Block B's explicit word-order matching step |
| Three-sentence elimination puzzles need all three words solved before any one answer is certain | Doesn't trust the "solve what you can, subtract the rest" method | Activity 2's explicit step-by-step elimination chain |
